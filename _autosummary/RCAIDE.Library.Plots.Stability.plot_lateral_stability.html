RCAIDE.Library.Plots.Stability.plot_lateral_stability

plot_lateral_stability#

plot_lateral_stability(results, save_figure=False, show_legend=True, save_filename='Lateral_Stability', file_type='.png', width=11, height=7)[source]#

Creates a multi-panel visualization of lateral-directional stability characteristics.

Parameters:

  • results (Results) –

    RCAIDE results data structure containing:
    • segments[i].conditions.frames.inertial.time[:,0]

      Time history for each segment

    • segments[i].conditions.aerodynamics.angles.phi[:,0]

      Bank angle history

    • segments[i].conditions.control_surfaces.aileron.deflection[:,0]

      Aileron deflection history

    • segments[i].conditions.control_surfaces.rudder.deflection[:,0]

      Rudder deflection history

    • segments[i].tag

      Name/identifier of each segment

  • save_figure (bool, optional) – Flag for saving the figure (default: False)

  • show_legend (bool, optional) – Flag to display segment legend (default: True)

  • save_filename (str, optional) – Name of file for saved figure (default: “Lateral_Stability”)

  • file_type (str, optional) – File extension for saved figure (default: “.png”)

  • width (float, optional) – Figure width in inches (default: 11)

  • height (float, optional) – Figure height in inches (default: 7)

Returns:

fig –

Handle to the generated figure containing three subplots:

  • Bank angle vs time

  • Aileron deflection vs time

  • Rudder deflection vs time

Return type:

matplotlib.figure.Figure

Notes

Creates visualization showing:

  • Roll attitude response

  • Lateral control inputs

  • Directional control inputs

  • Time history for each segment

Major Assumptions

  • Angles are in degrees

  • Time is in minutes

  • Positive deflections follow right-hand rule

Definitions

‘Bank Angle’

Roll attitude relative to horizon

‘Aileron Deflection’

Roll control surface position

‘Rudder Deflection’

Yaw control surface position
